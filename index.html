À proposAbout

Ce Fleet Carrier a été développé avec Claude Code (modèle Claude Opus 5.5). Les modèles 3D, les personnages et les sons viennent de projets gratuits et libres : les packs de Kenney (domaine public) et les icônes Phosphor (licence MIT). Le reste du mobilier (bornes d'arcade, hologrammes, SRV…) a été dessiné par l'IA, directement en code.

This Fleet Carrier was built with Claude Code (Claude Opus 5.5 model). The 3D models, characters and sounds come from free, open projects: the Kenney packs (public domain) and the Phosphor icons (MIT licence). The rest of the furniture (arcade cabinets, holograms, SRV…) was drawn by the AI, directly in code.

Technologies : Three.js, TypeScript et Vite pour le jeu, Node.js et socket.io pour le multijoueur.

Technologies: Three.js, TypeScript and Vite for the game, Node.js and socket.io for multiplayer.
