À proposAbout

Ce Fleet Carrier a été développé avec Claude Code (modèle Claude Opus 5.5). Les modèles 3D, les personnages et les sons viennent des packs de Kenney, dont nous avons acheté la collection complète, et les icônes de Phosphor (licence MIT). Les poissons de l'étang viennent de l'« Animated Fish Pack » de Quaternius (CC0). Le reste du mobilier (bornes d'arcade, hologrammes, SRV…) a été dessiné par l'IA, directement en code.

This Fleet Carrier was built with Claude Code (Claude Opus 5.5 model). The 3D models, characters and sounds come from the Kenney packs, whose complete collection we purchased, and the icons from Phosphor (MIT licence). The fish in the pond come from the “Animated Fish Pack” by Quaternius (CC0). The rest of the furniture (arcade cabinets, holograms, SRV…) was drawn by the AI, directly in code.

Technologies : Three.js, TypeScript et Vite pour le jeu, Node.js et socket.io pour le multijoueur.

Technologies: Three.js, TypeScript and Vite for the game, Node.js and socket.io for multiplayer.
